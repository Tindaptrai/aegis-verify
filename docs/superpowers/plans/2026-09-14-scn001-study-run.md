# SCN-001 Study and Run Verification Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans, tuần tự, không subagent/commit/push/merge theo user.

**Goal:** Kiểm frozen study inputs và chuỗi ba runner manifests, trả evaluation context unknown có window đúng 120 giây.

**Architecture:** Bytes-only API trong demo; dùng models/profile/scenario loader hiện có, không sửa engine/canonical/runner. Operator receipt là khai báo có pin hashes, không remote proof. Không tự đánh giá collection hoặc native event binding.

**Tech Stack:** Python >=3.11, pydantic hiện có, Decimal/json/hashlib, không dependency mới.

**Spec:** ../specs/2026-09-14-scn001-offline-evidence-design.md, mục 3,6,7.

## Constraints

- SCN-001 version0.1.0, assertions A01/A02/A03; exact window120s bằng nanoseconds; join hostname/asset_id/process_id [-5,+15] giây.
- Unknown collection, không chọn verdict; target/account/elevated và hashes cùng study cho A/B/C.
- Input config max1MiB/depth32/nodes50000. Chỉ execution final có finite elapsed_seconds number; không nới intake decoder chung.
- Ba manifests đầy đủ; không tái tạo missing/null. Status executed/exit0/timeoutfalse; payload/rule/host/executable khớp pins; A/B baseline, C fixed; rehearsal không relabel.
- Toàn bộ kit artifacts bytes hash khớp inventory, hai payload bằng nhau; không filesystem/network trong API này.
- Public errors sanitized; không raw lab/credential. Synthetic tests không thực thi runner payload.

## Files và interfaces

- Create `backend/app/demo/_study_contracts.py`: closed Study (pins, target, collection/time review references), operator RuleReceipt.
- Create `backend/app/demo/study.py`: `verify_study(study, *, study_sha256, scenario, profile, kit, artifacts)` trả Study đã validate; `_profile_rules` kiểm profile scope literals đã duyệt.
- Create `backend/app/demo/run.py`: `verify_run(*, study, study_sha256, scenario, profile, kit, artifacts, execution_start, execution_launched, execution, stdout, stderr, receipt)` trả CheckedRun(context, child_pid, run_label, study_sha256, input_sha256). Không nhận VerifiedStudy do caller tự tạo.
- Create `backend/app/demo/_execution_json.py`: bounded execution JSON đọc Decimal finite, duplicate keys/unknown field reject tại run contract.
- Create `backend/tests/test_scn001_study_run.py`; docs SCN001_STUDY_RUN.md và checkpoint.

Study JSON: kind=scn001_study, version0.1.0, study_id; pins có scenario/profile/kit/runner/payload/baseline/fixed (SHA256); target có environment_id, hostname, agent_id, account, elevated, executable (native), canonical_executable, collection_mode=direct, native_directory, canonical_paths[2], command_lines[2], rule_id, parent_sid, field_profile; collection_reference,time_reference. Hai paths/commands ordered original,renamed; require khác nhau, commands chỉ khác tên filename. Không suy literal canonical từ native path hoặc executable.

Receipt JSON: kind=scn001_rule_receipt, version0.1.0, run_id,study_sha256,execution_sha256, account,elevated, before_rule_sha256,after_rule_sha256,before_utc,after_utc,confirmed_by,before_reference,after_reference. Timestamp receipt bao toàn run; không tự xác thực operator.
